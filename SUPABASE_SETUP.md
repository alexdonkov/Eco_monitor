# Настройка на Supabase — стъпка по стъпка

Отнема около 15 минути. Нищо не се инсталира.

## 1. Проект
1. Влезте в https://supabase.com с GitHub акаунта си → **New project**.
2. Име: `ecomonitor`. Регион: **Central EU (Frankfurt)** — най-близо до България.
3. Запишете паролата на базата данни на сигурно място (не в GitHub).

## 2. Таблици и данни
1. **SQL Editor → New query** → поставете цялото съдържание на `database/schema.sql` → **Run**.
2. Нова заявка → `database/seed.sql` → **Run**. Накрая трябва да видите таблица с 10 места и броя измервания.
3. **Table Editor** — проверете, че има 5 таблици: `profiles`, `indicators`, `locations`, `measurements`, `alerts`.

## 3. Вход с имейл
1. **Authentication → Sign In / Providers → Email** — трябва да е включен.
2. За по-лесно тестване: изключете **Confirm email**. Така новите акаунти могат да влизат веднага. *(Преди защитата можете да го включите отново.)*

## 4. Ключове
1. **Project Settings → API**. Копирайте **Project URL** и **anon public** ключа.
2. Копирайте `src/js/config.example.js` като `src/js/config.js` и поставете двете стойности.
3. `config.js` е в `.gitignore` — **не се качва** в GitHub.

> **Защо anon ключът е безопасен в браузъра?** Той дава само правата на „гост“. Какво може да прави всеки потребител, решават RLS политиките в базата, а не ключът. **Никога** не слагайте `service_role` ключа в кода.

## 5. Роля „ръководител“
1. Регистрирайте се в приложението с имейла на ръководителя.
2. SQL Editor → `database/make_leader.sql` (сменете имейла) → **Run**.

## 6. Стартиране
1. Отворете папката на проекта във VS Code → десен бутон върху `src/index.html` → **Open with Live Server**.
2. Трябва да видите картата с 9 места. Ако виждате жълта лента „Липсва config.js“, върнете се на стъпка 4.

## 7. Тест на сигурността (RLS)
Попълнете `docs/RLS_TESTS.md` с три акаунта: гост (без вход), член и ръководител.
